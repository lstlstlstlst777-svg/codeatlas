## MCP server 设计：只暴露检索，不暴露"帮我回答"
`src/codeatlas/mcp/server.py`，两个工具：`search_code` / `get_symbol`。

**关键决策**：删掉了最初的 `ask_codebase` / `read_code` / `index_status`。
理由：宿主（Codex）本身就是 LLM，会归纳、会读文件、会写代码；
再包一层"我帮你答"是重复劳动，答案经过两个模型后**出错无法归因**。
副作用正合适：本进程不需要 LLM key，启动更快、失败面更小。

`get_symbol` 凭什么不能用 grep 代替：`grep -w zmalloc_used_memory` 返回的是
**调用点**（config.c/evict.c…），定义本体要靠人再筛；符号表里"定义"是有类型的 chunk，
可以直接给。实测 `get_symbol` 3ms（纯内存查表）。

### 三类必须处理的情况（都已处理 + 有测试）
| 情况 | 实例 | 处理 |
|---|---|---|
| 同名多定义 | `aeApiCreate` 4 个平台文件 | 全返回 + `⚠️ 同名定义 4 处` |
| 长函数切段 | `RM_Call` 21 段 / `rdbLoadObject` 11 段 | 按行号排序 + `[1/21]` |
| 拼错 | `zmalloc_used_memroy` | 给相近符号（公共前缀打分） |

### 两个输出层的坑
1. **前导注释吃光预算**：`expireIfNeeded` 有 100+ 行文档注释，截断 1500 字符
   的结果是"全注释、零代码"。改成注释只留 2 行 + `/* ... 省略 ... */`，预算全给代码。
2. **降级提示放末尾等于没放**：模型已经读完成绩单开始写结论了。改成放顶部。

## ISSUE-038 MCP SDK env=None 会过滤环境变量
- `StdioServerParameters(env=None)` 走 `get_default_environment()`，**只透传白名单**，
  `CODEATLAS_ROOT` 被静默丢掉 → 从 /tmp 启动就找不到索引（5 项冒烟全挂）。
- 调试客户端必须 `env={**os.environ}`；Codex 侧用 `[mcp_servers.codeatlas.env]` 显式给。
- **"能跑"必须说明前提**：在项目根测 MCP 等于没测，宿主 cwd 从来不是我们的项目。
- 反过来说，这次失败证明了 `_ready_or_error()` 守卫有效：返回可操作的检查清单，
  而不是 traceback——agent 拿到前者能自救，拿到后者只能放弃。
